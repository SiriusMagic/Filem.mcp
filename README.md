# Filem

Administrador de archivos para Android con servidor MCP, de la familia de Stone, Luma, Calculadora y Notas.

- **Inicio:** Recientes, Categorías (Descargas, Imágenes, Videos, Audio, Documentos, Apps), Destacados, Papelera y
  Almacenamiento interno con el espacio libre.
- **Carpetas:** lista o cuadrícula, ordenar por nombre/fecha/tamaño/tipo, carpeta nueva, cambiar nombre, copiar y mover
  («Pegar aquí»), compartir, destacar, información y papelera (30 días).
- **Buscar:** por nombre, sin importar acentos, con filtros de tipo, fecha y orden.
- **Modo MCP:** Claude, ChatGPT o Gateway Hub pueden listar, buscar, leer textos pequeños y (con permiso de escritura)
  crear carpetas, renombrar, copiar, mover y mandar a la papelera. Herramientas `files_*`.
- APK: `android/Filem-<versión>.apk`.
